# Product and delivery checklist

## Offers

### Premium Setup USB — $49.99

- Same core iTrustAI software setup as the other offers, on a more premium-looking USB package.
- Physical USB drive shipped to the customer.
- Core setup: Parrot OS, Hermes, Ollama, n8n, and a guided first agentic workflow.
- Include beginner-friendly setup and troubleshooting instructions.
- Before listing as ready to ship, document exact versions, hardware requirements, whether initial internet access is required, and what works offline afterward.
- Clarify shipping cost and delivery estimates at checkout.

### Standard Setup USB — $29.99

- Same core iTrustAI software setup and instructions on a standard USB drive, shipped to the customer.
- Clarify shipping cost and delivery estimates at checkout.

### DIY System Download — $9.99

- Same core iTrustAI system package for customers who want to install it themselves.
- Include a setup guide, supported hardware notes, checksums, and a clear statement of any initial internet or model-download requirements.
- Do not enable purchase until the final package is uploaded and tested.

## Store launch checklist

- [ ] Build and test each physical USB and digital download.
- [ ] Check third-party software and model redistribution terms.
- [ ] Set up the store on HTTPS.
- [ ] Connect an owner-controlled payment account; configure payouts directly with the provider.
- [ ] Add shipping, tax, refund, privacy, terms, and customer support details.
- [ ] Run a test checkout and verify receipts and protected downloads.
- [ ] Publish only after fulfillment has been tested end to end.
